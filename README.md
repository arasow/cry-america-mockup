# CRY America · Website Revamp Mockup

Clickable high-fidelity mockup of the unified CRY America website (cryamerica.org + events.cryamerica.org), designed by Ed for management review.

**This is a design review mockup, not production code.** People, donors, fundraisers and officers shown are fictional; program content (events, venues, projects) comes from the content inventory.

## View it

Open the published site (GitHub Pages) or open `index.html` in any browser.

Useful starting points:

- `#/` — Home
- `#/events` — Events hub (Walks, Galas, Holi, Dandiya, Other)
- `#/my-occasions` — My Occasions fundraising
- `#/action-centers` — Action Centers and volunteering
- `#/donate` — Donation flow
- `#/design-system` — Design system, tokens and route checklist

Use the dark **MOCK** bar at the top to switch roles (Visitor, Supporter, Event Admin, Action Center Coordinator, Super Admin) and Light / Dark styles.

## Publishing with GitHub Pages

Settings → Pages → Source: *Deploy from a branch* → Branch: `main`, folder `/ (root)` → Save. The site appears at `https://<owner>.github.io/<repo>/` within a minute or two.
